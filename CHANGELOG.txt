Bazarino — Changelog

2.0.1
- Fixed nested coupon form in checkout (RTL & LTR): Apply no longer submits the order form; Enter key applies the code.
- Corrected ARIA roles (color swatches, rating stars, payment icons, checkout steps, sliders, search combobox). Zero W3C validator errors.
- Moved inline SVG icon styles to a CSS class (.icon-fill).
- New package structure: RTL / LTR / Docs, illustrated Persian (Help.pdf) and English (Help-en.pdf) guides.

2.0.0
- Initial release: 8 home demos, Persian (RTL) and English (LTR) versions, 124 product pages, 12 blog articles, dark mode.
